```text
We are continuing the Inner Polis project.

Repository:
https://github.com/Kairon-2005/inner-polis

First, read the repository and treat it as the source of truth.
In particular, read:
- PROJECT_CONTEXT.md
- README.md
- constitution/
- characters/
- prompts/
- decisions/
- memory/

Do not redesign the philosophical system from scratch and do not silently overwrite established canon.
Strictly preserve the user's original expressions, including 去人性 / 反人性. Do not reinterpret them or add a new philosophical position.

Now begin Stage 1: build the first visual web version of Inner Polis.

Goal:
Turn the existing Markdown-based Inner Polis into a beautiful, contemplative interactive-book-style website hosted with GitHub Pages.

For this first web iteration:
1. Preserve the repo's Markdown files as the canonical content/source of truth.
2. Build a visual homepage / entrance to the Inner Polis.
3. Create dedicated character pages for Aeris, Iron Regent, Avalokita, Metis, Socrates, and The Little Prince.
4. Create conceptual spaces for:
   - Council Hall
   - Starfield
   - Archive
   - Observatory
   - Forge
   - Lake
   - Garden
5. Do NOT implement LLM/API chat yet.
6. Prioritize atmosphere, typography, navigation, symbolism, and information architecture.
7. The visual language should feel like a mixture of:
   - philosophical codex
   - interactive book
   - mythological inner world
   - restrained 2D game interface
   - night sky / marble / water / iron / parchment
   Avoid generic SaaS dashboard aesthetics.
8. Make it deployable on GitHub Pages.
9. Work directly in the repository, verify the site works, commit, and push.

Before implementation, inspect the existing repo carefully and propose a concise technical + visual direction based on the established canon. Then proceed with implementation.
```
